# Logo sources (fetched 2026-10-24)

On the page each file is a CSS mask painted with `--muted-foreground`, so only its shape is used; no brand colour ships.

All files came from the organisation's own site. Nothing from Wikipedia, Wikimedia or logo aggregators. Each viewBox is tight to the artwork, measured by rasterising in headless Chrome at about 4000 px and taking the alpha bbox, rounded outward to 0.01 units.

Common cleaning for every `<slug>.svg`: dropped the XML prolog, comments, `<style>`, `<title>`, ids, classes, `data-name`, `width`/`height`/`x`/`y`, inline style and every fixed fill. The root gets `fill="currentColor"`, or a currentColor rect under a mask for the knockout logos. No scripts, external refs or background rects were present in any source.
